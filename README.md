# stashr
A fast, Rust-powered TUI and CLI to manage your Git stashes: browse, preview diffs, apply/pop, rename, and drop—without leaving the terminal.

## Overview
stashr focuses on one thing: making Git stash workflows fast, safe, and pleasant.
- TUI for interactive management
- Built in Rust for speed and reliability

## Features (MVP)
- List stashes with message, branch, and timestamp
- Preview diffs before applying or popping
- Apply/pop with confirmation; drop and rename
